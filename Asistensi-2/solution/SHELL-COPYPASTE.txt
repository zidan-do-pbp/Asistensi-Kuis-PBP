SHELL-COPYPASTE.txt  |  python manage.py shell untuk Kuis 2 PBP
=====================================================================
Cara pakai:
  1. Masuk folder yang ada manage.py (soal1 / soal2 / soal3 / js-itemfinder)
  2. Aktifkan venv dulu, lalu:   python manage.py shell
  3. Paste blok di bawah. Keluar shell:   exit()   atau  Ctrl+Z lalu Enter (Windows)

ATURAN PASTE (sering bikin error):
  - Blok for/if di shell interaktif butuh BARIS KOSONG setelahnya. Kalau
    ragu, pakai versi satu baris (ditandai [1 BARIS]) atau pakai
    exec(open('seed_users.py').read()) yang sudah ada di folder soal.
  - Jangan ubah indentasi saat copy.
  - Satu paste = satu blok. Kalau error di tengah, ulangi blok itu saja.

Versi non-interaktif (tanpa masuk shell), cocok dari PowerShell:
  python manage.py shell -c "print(1+1)"
  Di PowerShell, pakai kutip ganda di luar dan kutip tunggal di dalam.

# A1. Import (selalu paling atas)
from django.contrib.auth.models import User, Group

# A2. Buat satu user biasa
User.objects.create_user("regular", password="aaaaa")

# A3. Buat tiga akun soal 2 sekaligus  [1 BARIS per baris]
regular = User.objects.create_user("regular", password="aaaaa")
editor = User.objects.create_user("editor", password="aaaaa")
owner = User.objects.create_user("owner", password="aaaaa")

# A4. Masukkan ke Group (Group Editor dan Owner dibuat oleh migrasi 0002)
editor.groups.add(Group.objects.get(name="Editor"))
owner.groups.add(Group.objects.get(name="Owner"))

# A5. Versi aman dijalankan berulang (tidak error kalau user sudah ada)
u, _ = User.objects.get_or_create(username="regular")
u.set_password("aaaaa")
u.save()

# A6. Lihat semua user dan group-nya
list(User.objects.values_list("username", flat=True))
for u in User.objects.all(): print(u.username, list(u.groups.values_list("name", flat=True)))

# A7. Cek apakah user punya role (sama dengan has_role di views.py)
User.objects.get(username="owner").groups.filter(name="Owner").exists()

# A8. Cabut role / ganti password / hapus user
editor.groups.remove(Group.objects.get(name="Editor"))
User.objects.get(username="regular").set_password("baru123")   # lalu .save()
User.objects.filter(username="regular").delete()

# A9. Superuser (hanya untuk /admin/, JANGAN dipakai untuk hak akses fitur)
#     Dari terminal biasa, bukan di dalam shell:
#       python manage.py createsuperuser
#       python manage.py changepassword <username>

# A10. Daftar group yang ada
list(Group.objects.values_list("name", flat=True))

# A11. Satu baris dari PowerShell (tanpa masuk shell)
python manage.py shell -c "from django.contrib.auth.models import User; User.objects.create_user('regular', password='aaaaa')"
