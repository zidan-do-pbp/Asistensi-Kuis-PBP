4. TABEL urls.py
========================================================================

4.1 ANATOMI path(...)  (ini yang sering membingungkan)

```
path("<alamat>", <nama_fungsi_view>, name="<nama_url>"),
```

| Bagian | Isi | Aturan | Contoh |
|--------|-----|--------|--------|
| "<alamat>" | URL yang diketik di browser (setelah domain) | string, tanpa "/" di depan, biasanya diakhiri "/", root = "" | "register/" -> http://127.0.0.1:8000/register/ |
| <nama_fungsi_view> | fungsi di main/views.py yang dijalankan | TANPA tanda kurung. Harus di-import di atas file. Nama persis sama dengan def di views.py | register |
| name="<nama_url>" | label untuk menyebut URL ini dari kode lain | bebas, tapi PAKAI YANG SAMA dengan yang dipanggil template/redirect. Konvensi: sama dengan nama fungsi | name="register" |

Cara memakai name:
```
Python  : redirect("main:register")            # "main" = app_name, "register" = name
Template: {% url 'main:register' %}            # tanpa parameter
Template: {% url 'main:edit_project' project.id %}   # dengan parameter
```

4.2 app_name
```
app_name = "main"      # di main/urls.py. Itu yang membuat awalan "main:" wajib dipakai
```
Kalau lupa app_name, {% url 'main:xxx' %} -> NoReverseMatch ("'main' is not a registered namespace").

4.3 IMPORT di urls.py (harus sama dengan nama fungsi di views.py)
```
from django.urls import path
from main.views import home, register, login_user, logout_user
```
atau  `from . import views`  lalu  `path("register/", views.register, name="register")`.

4.4 PARAMETER di URL (path converter)

| Converter | Menangkap | Contoh | Tipe di view |
|-----------|-----------|--------|--------------|
| <int:project_id> | angka bulat >= 0 | projects/3/edit/ | int 3 |
| <str:nama> | teks tanpa "/" | user/budi/ | "budi" |
| <slug:slug> | huruf-angka-strip | post/hello-world/ | "hello-world" |
| <uuid:id> | UUID | item/<uuid>/ | UUID |
| <path:p> | teks termasuk "/" | files/a/b.txt | "a/b.txt" |

ATURAN PARAMETER: nama setelah titik dua di urls.py HARUS SAMA PERSIS dengan nama parameter fungsi.
```
path("projects/<int:project_id>/edit/", edit_project, name="edit_project"),
def edit_project(request, project_id):       # project_id sama persis
```
Salah ketik (project_ud, id vs project_id) -> TypeError: got an unexpected keyword argument.

4.6 [TAMBAHAN] kalau kamu HARUS menambah route baru (tidak ada di template)
Langkah: (1) tulis fungsi di views.py, (2) tambah ke import di urls.py, (3) tambah baris path(...), (4) panggil dari template pakai {% url %}.
```
# views.py
def about(request):
    return render(request, "main/about.html")
# urls.py
from main.views import about
path("about/", about, name="about"),
# template
<a href="{% url 'main:about' %}">Tentang</a>
```
Route dengan parameter + nama bebas:
```
path("projects/<int:project_id>/", project_detail, name="project_detail"),
def project_detail(request, project_id): ...
{% url 'main:project_detail' project.id %}
```
Class-based view bawaan: path("login/", auth_views.LoginView.as_view(template_name="main/login.html"), name="login")

5.2 REQUEST (apa yang bisa dibaca dari request)

| Ekspresi | Isi |
|----------|-----|
| request.method | "GET" atau "POST" (HURUF BESAR, pakai kutip) |
| request.POST | data form (dict-like). request.POST.get("theme") |
| request.GET | query string ?a=1 |
| request.user | user login. .username, .is_authenticated, .groups |
| request.session | dict di server: session["k"], .get("k", default), .pop("k", None) |
| request.COOKIES | dict cookie dari browser: request.COOKIES.get("last_login") |
| request.body | isi mentah (bytes). JSON: json.loads(request.body) |
| request.FILES | upload file (jarang) |

5.3 RESPONSE dan STATUS CODE

| Situasi | Kode | Cara |
|---------|------|------|
| Sukses tampil halaman | 200 | return render(request, "main/x.html", {...}) |
| Sukses lalu pindah halaman | 302 | return redirect("main:nama") |
| Request salah / nilai tidak valid | 400 | return HttpResponseBadRequest("pesan") |
| Belum login | 302 ke LOGIN_URL?next=... | @login_required |
| Login tapi tidak berhak | 403 | raise PermissionDenied  (atau return HttpResponseForbidden()) |
| Objek tidak ada | 404 | get_object_or_404(Model, pk=id)  (atau raise Http404) |
| Method salah | 405 | @require_POST  atau  return HttpResponseNotAllowed(["POST"]) |
| JSON | 200/201/400 | JsonResponse({...}, status=201) |
| CSRF salah/hilang | 403 | lupa {% csrf_token %} atau header X-CSRFToken |

5.4 POLA FORM (GET/POST) -- pola yang dipakai register, create, edit
```
def nama_view(request):
    if request.method == "POST":
        form = NamaForm(request.POST)                  # edit: NamaForm(request.POST, instance=obj)
        if form.is_valid():
            form.save()
            return redirect("main:tujuan")
    else:
        form = NamaForm()                              # edit: NamaForm(instance=obj)
    return render(request, "main/template.html", {"form": form})
```
Jatuh ke render = POST tidak valid (form + error tampil) dan GET (form kosong).

5.5 SESSION vs COOKIE

| | Session | Cookie |
|---|---------|--------|
| Disimpan di | server (browser hanya pegang sessionid) | browser |
| Baca | request.session.get("theme", "light") | request.COOKIES.get("announcement_dismissed") |
| Tulis | request.session["theme"] = "dark" | response.set_cookie("nama", "nilai", max_age=..., httponly=True, samesite="Lax") |
| Hapus | request.session.pop("theme", None) | response.delete_cookie("nama") |
| Catatan | JANGAN session.flush() kalau user harus tetap login | set_cookie dipanggil pada response yang DI-RETURN (buat redirect dulu) |

Argumen set_cookie: key, value, max_age (detik; 3600 = 1 jam; 604800 = 7 hari), httponly=True (JS tidak bisa baca), samesite="Lax", secure=True (hanya HTTPS, tidak perlu di lokal), path="/".

5.6 PERMISSION / ROLE
```
def has_role(user, role_name):

Larangan di kuis: is_superuser untuk hak akses. Cek role SELALU di view (server). Menyembunyikan tombol di template hanya kosmetik.

7. KODE JAWABAN Django (views.py lengkap)
========================================================================

TEMPLATE: soal1/main/views.py

```
from django.contrib.auth import login, logout
from django.contrib.auth.forms import AuthenticationForm, UserCreationForm
from django.http import HttpResponseNotAllowed
from django.shortcuts import redirect, render
from django.utils import timezone

def home(request):
    return render(
        request,
        "main/home.html",
        {"last_login": request.COOKIES.get("last_login")},
    )

def register(request):
    if request.method == "POST":
        form = UserCreationForm(request.POST)
        if form.is_valid():
            form.save()
            return redirect("main:login")
        # POST tidak valid: tidak ada User dibuat, jatuh ke render di bawah (form + error)
    else:
        form = UserCreationForm()
    return render(request, "main/register.html", {"form": form})

def login_user(request):
    if request.method == "POST":
        form = AuthenticationForm(request, data=request.POST)
        if form.is_valid():
            login(request, form.get_user())
            response = redirect("main:home")
            # BONUS: max_age=3600, httponly=True, samesite="Lax"
            response.set_cookie(
                "last_login",
                timezone.localtime().strftime("%Y-%m-%d %H:%M:%S"),
                max_age=3600,
                httponly=True,
                samesite="Lax",
            )
            return response
    else:

async function loadReports() {

async function submitReport(event) {
  const app = document.getElementById("app");
  const submitButton = document.getElementById("submit-button");

  event.preventDefault();

  if (isSubmitting || isLoading) {
    return;
  }

  const title = form.elements["title"].value.trim();
  const location = form.elements["location"].value.trim();
  const status = form.elements["status"].value;

  if (!title || !location || !["hilang", "ditemukan"].includes(status)) {
    formMessage.textContent =
      "Judul dan lokasi wajib diisi, status harus hilang atau ditemukan.";
    return;
  }

  const csrfToken = form.elements["csrfmiddlewaretoken"].value;

  isSubmitting = true;
  formMessage.textContent = "";
  submitButton.disabled = true;
  submitButton.textContent = "Mengirim...";

  try {
    const response = await fetch(app.dataset.createUrl, {
      method: "POST",
      headers: {
        "Content-Type": "application/json",
        "X-CSRFToken": csrfToken,
      },
      body: JSON.stringify({ title, location, status }),
    });

    if (!response.ok) {
      let message = "Gagal menyimpan laporan. Coba lagi.";
      //BONUS soal 4: HTTP 400 tampilkan pesan dari data.errors
      if (response.status === 400) {
        const data = await response.json();
        const details = Object.values(data.errors || {}).flat();
        if (details.length > 0) {
          message = details.join(" ");
        }
      }
      throw new Error(message);
    }

    await response.json();

    form.reset();
    //TRAP: isSubmitting harus false SEBELUM closeModal(), kalau tidak modal tidak pernah menutup
    isSubmitting = false;
    closeModal();
    await loadReports();
  } catch (error) {
    formMessage.textContent = error.message;
  } finally {
    isSubmitting = false;
    submitButton.disabled = false;
    submitButton.textContent = "Simpan";
  }
}
